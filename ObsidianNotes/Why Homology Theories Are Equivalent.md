#Algebraic-Topology #Geometry #Homology #Topology
There're many different homology theories but surprisingly they seem to describe one same thing. Homology theories vary from simplicial, singular, cellular, to Čech, de Rham. (The list needs further refinement, these are just what I have learned.) There starting points seem to be completely different, simplicial begins with cutting topological spaces into simplicials, singular is a more topological object which is defined via mapping classes for all topological spaces, Čech is purely combinatorial, and de Rham is an extension of calculus, which is defined only for differential manifolds. However, despite this variety of starting points, they eventually give about the same information about a geometrical object and they're isomorphic on suitable objects. Vaguely this is because homology theory investigates a naturality of these geometrical objects which is best described by the language of homological algebra, which all these homological theories adopt. This essay aims to present a more explicit sight on why these theories are essentially identical.
First let's review two basic commons about all these theories, for simplicity we only consider about cohomology: the Mayer-Vietories sequence, vanishing for some simple (basically this means contractible) space (the Poincaré lemma). If we further assume that the geometric objects we are interested in can have a good cover (an open cover such that on all finite non-empty intersections, cohomology vanishes), then we can form the Čech double complex, which is essentially a generalization of Mayer-Vietories sequences, and use the [Acyclic Assembly Lemma] to show that the cohomology theory we are considering about is isomorphic to the Čech cohomology with respect to the good cover. (Furthermore, using the categorical tool, limits, we can conclude that the Čech cohomology is independent of the choice of a good cover and define a more natural object also called the Čech cohomology which depends only on the geometric object.) So now all these homology theories are reduced to the Čech cohomology, and the latter is a purely combinatorial object, which reveals the essential meaning of a homology theory. If we further consider the nerve of the good cover, by the [Nerve Theorem], homology theories are essentially drawing nerves on the geometric object and counting holes of these nerves. Hence we have drawn a path to reduce all homology theories to the Čech cohomology and have explained why the motto, "homology is about counting holes", actually works.
