#Algebraic-Geometry 
Let $S$ be a graded ring. The geometric structures of $\text{Proj}\,S$ is determined by the quotients of homogeneous elements in $S$ but not by their absolute values. (Just notice that we only consider the zero degree part of localizations.)
With this idea at mind, we could understand many phenomena.

#### A. Vernonese Embedding
See [[About Veronese Embedding And An Idea]].
#### B. Closed Subschemes & Morphisms
Let $\varphi$ be a graded homomorphism between two graded rings. If $\varphi_d$ are isomorphisms for all $d>d_0$, then the induced morphism between schemes is an isomorphism. See Hartshorne, Ex.II.2.14.
Apply this to quotient rings of $S$, we see that two ideals determine one same closed subscheme if they are the same after some $d_0$.
So we could replace a homogeneous ideal $I$ with $I_{\geq d_0}=\bigoplus_{d\geq d_0}I_d$ and get the same closed subscheme. See Hartshorne, Ex.II.3.12.
Also we could replace $I$ with its saturation.
#### C. Trick of Twisting Up Then Down
We often have better things when the degree $n$ is large enough, so we could prove $\mathcal{F}(n)\cong \mathcal{G}(n)$, then tensor with $\mathcal{O}(-n)$ to get $\mathcal{F}\cong \mathcal{G}$. Hartshorne, II.5.17~19 is an example.

#### D. Category of Coherent $\mathcal{O}_X$-modules when $X$ is Projective
Assume that $S_0$ is a finitely generated $k$-algebra for some field $k$, $S_1$ is a finitely generated $S_0$-module, and $S$ is a graded ring generated by $S_1$ as an $S_0$-algebra. Denote $X=\mathrm{Proj}\,S$ and $K=\mathrm{Frac}\,S$. (Notice that only homogeneous elements are inverted so this is actually not a field.)
Define an equivalence relation $\approx$ on graded $S$-modules by saying $M\approx M'$ if there is an integer $d$ such that $M_{\geq d}\cong M'_{\geq d}$. Also say that a graded $S$-module is quasi-finitely generated if it is equivalent to a finitely generated module.
**Theorem.** The functors $\tilde{\;}$ and $\Gamma_*$ induce an equivalence of categories between the category of quasi-finitely generated graded $S$-modules modulo the equivalence relation $\approx$, and the category of coherent $\mathcal{O}_X$-modules.
**Proof.** For any coherent sheaf $\mathcal{F}$ over $X$, Hartshorne II.5.15 showed that there's a natural isomorphism $\beta:\Gamma_*(\mathcal{F})\tilde{\;}\rightarrow\mathcal{F}$. So it suffices to show that for any finitely generated module $M$, the natural homomorphism $\alpha:M\rightarrow\Gamma_*(\widetilde{M})$ is an isomorphism in degrees large enough.
***Step 1.*** By Harthorne I.7.4, there exists a filtration$$0=M_0\subset M_1\subset\cdots\subset M_r=M$$such that $M_i/M_{i-1}\cong (S/\mathfrak{p_i})(n_i)$. Applying the snake lemma to

we see that it suffices to assume $M=(S/\mathfrak{p})(n)$. Furthermore, if we set $Z=\mathrm{Proj}\,S/\mathfrak{p}$ and $f$ induce by the quotient map, then $\Gamma(X,(S/\mathfrak{p})\tilde{\;}(n))=\Gamma(X,f_*\mathcal{O}_Z(n))=\Gamma(Z,\mathcal{O}_Z)$. So we could assume that $S$ is and integral domain and $M=S$.
***Step 2.*** Now injectivity of $\alpha$ is trivial. For surjectivity, suppose $X$ is covered by $\{D_+(f_i)\,:\,1\leq i\leq r, f_i\in S_1\}$. Then any element of $\Gamma(X,\mathcal{O}_X(n))$ is represented by compatible elements $s_i=a_i/f_i^{k_i}\in\mathrm{Spec}\,S_{(f_i)}$. These are essentially an element $x\in K$ since they're identical on intersections $D_+(f_if_j)$ and $S$ is an integral domain. Therefore we have shown that $\Gamma(X,\mathcal{O}_X(n))=\{x\in K\,:\,\mathrm{deg}\,x=n\text{ and }\exists\,m\;\forall 1\leq i\leq r\;\;f_i^mx\in S\}$. Set $T=\Gamma_*(\mathcal{O}_X)$, we have $S\subset T$.
**Claim.** $T$ is a finitely generated $S$-module. (For proof, see Hartshorne, the last part of the proof of II.5.19.)
Suppose $T$ is generated by $x_1,\dots,x_l$ as an $S$-module. There exists $m$ such that for any $i$ and $j$, $f_i^mx_j\in S$. Therefore, for any $d\geq m+\max_{1\leq j\leq l}\mathrm{deg}\,x_j=:d_0$, $T_d=S_d$.$$\tag*{$\square$}$$**Remark.** The process of simplifying the problem in step 1 is very useful!
